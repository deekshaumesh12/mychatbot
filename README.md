So this is a small chatbot that i created, i mean it can't do much, but that doesn't mean it can't do anything:). It's a bit slow, BUT the response is worth the wait, run it in any browser and enjoy!

This project now includes a static front-end demo chat UI (`index.html`) that runs a local responder in the browser. It's safe to deploy on Vercel as a static site.

Quick deploy to Vercel:

1. Install the Vercel CLI (optional):

```bash
npm i -g vercel
```

2. From the project root run:

```bash
vercel deploy --prod
```

Or connect the repository in the Vercel dashboard — the project is configured to serve `index.html` as a static site via `vercel.json`.

Local run (static):

Open `index.html` in your browser or serve it with any static server.
